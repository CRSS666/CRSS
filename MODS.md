# CRSS Mods

This document contains information about which mods the Main CRSS Server uses.

If you want to suggest any addition, change or removal of a certain mod or mod
feature, you can tell us on [our discord](https://discord.crss.cc/) or make an
issue in this repository.

The CRSS 3 branch will have a `PLUGINS.md` file, containing similar info, but
instead applying to bukkit plugins.

The CRSS 2² branch will have a `MODS.md` file as well, containing the mods in
the server, and required Client mods.

## Notes!

- We will try to support as much mods as we can,
but if any of them conflict, we will pick
the most-used or most-requested option.

- If one of the mods is giving you a super-specific
'Millions to one!' issue or you have a nitpick with
one of the mods, yell at us at discord.
